# CAMBench Coding

Status: unavailable for a public local run. No score has been produced.

The [AML benchmark catalog](https://agentmemories.ai/docs#doc-en-benchmarks)
identifies CAMBench Coding as 150 software-engineering tasks evaluated in relevant
and noisy memory conditions (300 attempts). The [official public release](https://github.com/AML-memory/agent-memory-leaderboard#-evaluation-at-a-glance)
explicitly says the coding track is unreleased and excludes private tasks,
verifier materials, and protected annotations. No public corpus or local native
evaluator is supplied by that release.

This is not the unrelated cryptographic API or Lean theorem-proving CamBench.
Local Add/Search endpoints alone cannot recreate the withheld task suite.
To run this exact benchmark, obtain an authorized released corpus and verifier,
or use AML's hosted evaluation with an issued key and registered public endpoints.
The current user request selects public local datasets, so no hosted job was submitted.

`status.json` records this availability check; `results/` is reserved for actual runs.
