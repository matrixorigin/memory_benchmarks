# Coding Datasets

- [CAMBench Coding](cambench/README.md): blocked by unreleased corpus and verifier.
- [SWEContextBench](swecontextbench/README.md): public Full historical-issue retrieval.

Each dataset has its own directory. SWEContextBench measures retrieval of related
historical issues through Add/Search. It does not generate patches or execute
the native Docker correctness evaluator; retrieval recall is not coding success.
